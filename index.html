CostyCNC CM8: a CNC program in your browser, not just a converter

CostyCNC CM8 runs directly in your browser, with no installation, while providing tools for preparing and controlling CNC hot-wire cutting. You can create text with or without an outline, resize images, view and edit G-code, set feed rate and temperature, and also control a rotary table.

Path generation starts from a raster image. CostyCNC extracts raw paths made of pixel coordinates and applies an algorithm that progressively searches for the nearest paths, rotating and joining them at the closest points. The paths are progressively merged until they form a single continuous path.

The resulting path is then processed through a modified version of Potrace to obtain the vector contours used for the subsequent G-code generation.

The fact that CM8 runs in a browser does not mean that it is a simplified program: image processing, path construction, and G-code generation are performed directly in the web page.
